# VivaMonarch 🌿🦋


Monarch butterflies are one of the world’s most iconic migratory insects, traveling thousands of kilometers between North America and Mexico or California each year. Their striking orange-and-black wings and remarkable life cycle make them a natural wonder now facing serious threats from habitat loss, pesticides, climate extremes, and disease.

![Monarch Swarm](ButerflySwarm.jpeg)

---

## ✨ Features
- **Pastel modern design** optimized for desktop & mobile  
- **Micro-animations**: hover lifts, scroll reveals, floating hero image  
- **Responsive layout** with sticky navigation & hamburger menu  
- **Educational sections**: Biology, Range, Migration, Threats, Actions, Outlook  
- **Accessible**: semantic markup, prefers-reduced-motion support  
- **Assets included**: images and video background  

---

## 🚀 Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/viva-monarch.git
   cd viva-monarch
    ````

2. Open `index.html` in your browser.
   That’s it! 🎉
